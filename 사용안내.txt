FOLIO — 로컬 문서 서재
====================

시작
1. Start-Folio.cmd를 두 번 클릭합니다.
2. 브라우저에서 http://localhost:4173 을 엽니다.
3. PDF, JPG, JPEG, PNG, WebP, TXT, MD 파일을 여러 개 선택하거나 서재에 끌어다 놓습니다.

이 PC에는 Node.js가 설치되어 있습니다. 다른 PC에서 실행하려면 Node.js 22 이상이 필요합니다.
배포용 라이브러리는 dist/vendor에 포함되어 있으므로 실행할 때 다운로드하거나 설치하지 않습니다.
실행 창을 닫으면 로컬 서버가 종료됩니다. 같은 포트가 이미 열려 있으면 기존 주소를 사용하세요.

읽는 방법
- 페이지 가장자리 클릭/드래그, 좌우 버튼, 키보드 ← →: 페이지 넘기기
- 책 위에서 마우스 휠 위/아래: 확대/축소 (75%~300%)
- 확대 상태에서 마우스로 드래그: 문서 위치 이동
- 오른쪽 위 배율 클릭 또는 숫자 0: 100%로 복원
- 키보드 + / -: 확대/축소
- 아래 페이지 번호 입력 후 Enter: 해당 페이지로 이동
- 페이지: 페이지 바로가기
- 한 쪽 보기: 한 페이지씩 표시
- 자동 넘김: 3초, 5초, 8초 간격
- 확대: 현재 페이지의 별도 확대 창
- Esc: 서재로 돌아가기 (확대 창에서는 창 닫기)

저장
문서 파일과 읽은 위치는 현재 브라우저의 IndexedDB에 저장됩니다.
서버 업로드, 클라우드 저장, AI API 호출, 분석 추적은 없습니다.
localhost와 127.0.0.1, 다른 포트, 다른 브라우저는 각각 다른 서재입니다.
브라우저 데이터를 지우거나 저장 공간이 부족하면 데이터가 삭제되거나 저장이 실패할 수 있습니다.
원본 파일을 따로 보관하세요. 파일당 100 MB까지 추가할 수 있습니다.
같은 내용의 파일을 다시 추가하면 중복을 건너뜁니다.
초기 체험 문서 2개는 예시 콘텐츠이며 실제 업로드 문서와 SAMPLE 표시로 구분합니다.

현재 지원 범위
- PDF: 페이지 표시, 넘김, 확대, 원본 다운로드
- JPG/PNG/WebP: 파일 하나당 하나의 문서
- TXT/MD: UTF-8 텍스트를 페이지로 나눠 표시. Markdown 서식 해석은 하지 않습니다.
- 암호가 설정된 PDF는 암호를 해제한 사본을 추가해야 합니다.
- DOCX/PPTX/HWP/XLSX는 먼저 PDF로 변환해야 합니다.
- PDF 본문 검색, 텍스트 선택, 내부 링크, 주석, 공동 편집은 아직 구현하지 않았습니다.
- 낮은 해상도의 스캔본/이미지는 확대하더라도 원본 이상의 세부 정보를 복원하지 않습니다.

웹으로 옮기기
dist 폴더는 정적 웹사이트 배포용 파일입니다.
소스: dist/app.js, dist/style.css, dist/index.html
로컬 서버: server.mjs (127.0.0.1에만 연결)
재설치: npm install --ignore-scripts --omit=optional --no-audit --no-fund
라이브러리 재복사: npm run prepare-assets
문법 검사: npm run check

웹사이트로 배포해도 현재 구조는 방문자별 브라우저 저장입니다.
여러 기기에서 같은 문서를 보거나 관리자 업로드 문서를 다른 사람과 공유하려면
사용자 인증, 파일 저장소, 문서 목록 데이터베이스가 별도로 필요합니다.
호스팅/저장소 서비스와 요금, 무료 한도, 초과 과금 조건을 확인하고 승인을 받은 후 연결해야 합니다.
현재 원격 저장소, 클라우드 자원, 배포, 유료 서비스는 생성하지 않았습니다.

사용 라이브러리
PDF.js 6.5.438 — Apache-2.0
https://github.com/mozilla/pdf.js
StPageFlip 2.0.7 — MIT
https://github.com/Nodlik/StPageFlip
라이선스 원문은 dist/vendor의 각 라이브러리 폴더에 포함되어 있습니다.

검증 (2026-11-03)
- PDF, 한글 TXT, PNG 파일 일괄 추가
- PDF 14페이지 파일의 양면 표시와 확대
- 파일과 읽은 페이지의 새로고침 후 유지
- 제목 검색
- 마우스 휠 확대 및 드래그 이동, 100% 복원
- JavaScript와 서버 문법 검사
대용량 100 MB/수천 페이지 파일과 모든 브라우저 조합은 아직 검증하지 않았습니다.
